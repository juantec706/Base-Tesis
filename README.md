# Base-Tesis
Estos son los principales códigos que utilicé para crear la base de datos de mi tesis y analizarla econométricamente. La base de datos que utilicé ya estaba limpia. Aquí el trabajo fue principalmente modificar la base para que me diera la información que yo quería: básicamente saber si hubo alternancia política o no.
En donde hubo un mayor trabajo de scrapeo, análisis exploratorio de los datos y corrección de errores fue en las bases que tienen nombre de estados. Aquí los datos estaban como me los dieron los OPLES, los cuales estaban sucios.
